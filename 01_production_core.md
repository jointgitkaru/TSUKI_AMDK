# Production Core

## Production Philosophy

The project follows a strict production chain. No generation exists in isolation.

```
DEFINE → REFERENCE → DESIGN → GENERATE → REVIEW → SELECT → PRESERVE → CONTINUE
```

Every asset must be classified before entering the production pipeline:

```
[CHARACTER_REFERENCE]
[LOCATION_REFERENCE]
[OBJECT_REFERENCE]
[STYLE_REFERENCE]
[KEYFRAME]
[START_FRAME]
[END_FRAME]
[VIDEO_SOURCE]
[AUDIO_REFERENCE]
[CONTINUITY_FRAME]
[MASTER]
```

## Canon System

The universe operates on four canon levels:

### Level 01 — CORE CANON

Fundamental elements that must not change without explicit decision:

- Character identities and relationships
- Official visual appearance of locked characters (Tsuki, Simba)
- Kitchen characteristics and geography
- Visual language (16mm aesthetic)
- Established narrative rules
- Recurring elements and mythology threads

### Level 02 — ESTABLISHED CANON

Elements approved during production:

- Recurring objects
- Specific layouts
- Costumes
- Reference framings
- Behaviors and atmospheres

### Level 03 — EXPERIMENTAL

Material not yet approved.

```
EXPERIMENT ≠ CANON
```

Nothing experimental may be used automatically as a continuity reference.

### Level 04 — APPROVED MASTER

Officially approved material. Can be used as:

- Ingredient / Reference
- Start Frame / End Frame
- Continuity Frame
- Production Asset

## Narrative Layers

The series operates on three simultaneous narrative layers:

```
LAYER 1: TSUKI (voice/narration) → full public access
LAYER 2: SIMBA (inaudible thought) → inaudible to humans, audible to audience
LAYER 3: PET NETWORK (dialogue) → inaudible to humans, audible to audience
```

### Access Rules

- Pets understand humans. Humans do not understand pets.
- Pets can try to speak to humans → humans hear animal sounds.
- Tsuki has ZERO ironic consciousness. Simba has TOTAL.
- Tsuki speaks to the archive — not to audience, not to Simba.
- Simba thinks — he does not speak to the public. The public accesses the thought.

## Anti-Cliché Protocol

The following are PROHIBITED in all production:

- AI clichés ("arrepio pela espinha", "olhos encontraram", "silêncio pesado")
- Excessive adjective use
- Naming emotions directly ("she felt sadness")
- Purple/decorative prose
- Repeating the same creative approach across different episodes
- Forced moral resolutions or neat endings
